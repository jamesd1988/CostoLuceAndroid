# Costo Luce Android

Applicazione Android per stimare il costo variabile della corrente dai kWh e sperimentare il recupero dei consumi dal Portale Consumi dopo l'accesso SPID/CIE.

La sincronizzazione del portale e' sperimentale: non viene richiesto di condividere credenziali con l'app e la lettura della pagina non e' garantita.
